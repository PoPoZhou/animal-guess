# 猜猜我心裡的動物

你在心裡想一種動物，AI 一題一題問，把答案猜出來，並把推理過程攤開給你看。

**立即試玩：** https://popozhou.github.io/animal-guess/

## 這個作品在做什麼

這是「教 AI 做事」的期末作品。AI 只靠一張知識表和幾條規則推理，不需要伺服器，也不呼叫外部 AI。每問一題，畫面都會顯示：

- 還剩幾種動物，以及各分類還剩幾種
- 為什麼問這一題
- 這題排除了哪些動物
- 目前最可能的前三名和把握度
- 猜完後的檢討：哪一題最關鍵、哪些答案和知識表不一樣

猜錯時可以按「教我」修正知識表。修正只存在自己的瀏覽器。

## AI 怎麼問

| 階段 | 問什麼 | 例子 |
| --- | --- | --- |
| 1. 種類 | 屬於哪一類動物 | 哺乳類、鳥類、魚類、爬蟲類、兩棲類、其他 |
| 2. 顏色 | 常見顏色，最多 3 題 | 黑、白、灰、棕、黃橘、紅粉、綠、藍 |
| 3. 細部特徵 | 習性和外型 | 會飛、有角、長脖子、住海裡、有毒 |
| 4. 品種 | 只有狗和貓會問到 | 立耳或垂耳、長毛、短腿、扁臉、捲尾 |

每局最多問 20 題、猜 3 次。AI 每次挑最接近對半切的問題；答案和知識表不合時不會直接刪掉那種動物，因為玩家也可能答錯。

## 檔案

```
animal-guess/
├─ index.html      網頁入口
├─ README.md       說明
├─ css/
│  └─ style.css    外觀
├─ js/
│  ├─ data.js      知識表和各階段的問題。要教 AI 新知識，改這個檔案。
│  ├─ engine.js    AI 的推理規則
│  └─ app.js       畫面與互動
└─ tests/
   └─ run.html     自動測試
```

## 測試

打開 https://popozhou.github.io/animal-guess/tests/run.html ，AI 會對每種動物各玩一局並列出結果。

## 在自己電腦上看

網頁用到 JavaScript 模組，直接雙擊 `index.html` 可能打不開，請在這個資料夾執行：

```
python -m http.server 8000
```

再用瀏覽器打開 http://localhost:8000/ 。
